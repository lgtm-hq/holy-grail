## What is Marshmallow?

[Marshmallow](https://marshmallow.readthedocs.io/) is a Python library for object serialization and deserialization. It converts complex data types to and from native Python data types, with built-in validation.

> Marshmallow is particularly useful for validating API request/response data against schemas generated from OpenAPI specifications.

## Basic Usage

### Define a Schema

```python
from marshmallow import Schema, fields

class UserSchema(Schema):
    id = fields.Int(dump_only=True)
    name = fields.Str(required=True)
    email = fields.Email(required=True)
    created_at = fields.DateTime(dump_only=True)
```

### Serialize (Dump) Data

```python
user_data = {
    "id": 1,
    "name": "John Doe",
    "email": "john@example.com"
}

schema = UserSchema()
result = schema.dump(user_data)
print(result)
# {'id': 1, 'name': 'John Doe', 'email': 'john@example.com'}
```

### Deserialize and Validate (Load) Data

```python
input_data = {
    "name": "Jane Doe",
    "email": "jane@example.com"
}

schema = UserSchema()
result = schema.load(input_data)
# Returns validated data or raises ValidationError
```

class UserCreateRequest(Schema):

## API Validation Examples

### Validate Request Data

```python
from marshmallow import ValidationError

data = {
    "firstName": "User FName",
    "lastName": "User LName",
    "emailAddress": "new_user@example.com"
}

schema = UserCreateRequest()

try:
    validated = schema.load(data)
except ValidationError as e:
    print(f"Request validation failed: {e.messages}")

# Proceed with validated data
```

### Validate Response Data

```python
import requests
from marshmallow import ValidationError

response = requests.post(
    url="https://api.example.com/users",
    json=data
)

response_data = response.json()
schema = UserCreateResponse()

try:
    validated = schema.load(response_data)
except ValidationError as e:
    print(f"Response validation failed: {e.messages}")
```

## Advanced Features

### Nested Schemas

```python
class AddressSchema(Schema):
    street = fields.Str()
    city = fields.Str()
    country = fields.Str()

class UserSchema(Schema):
    name = fields.Str()
    address = fields.Nested(AddressSchema)
```

### Custom Validation

```python
from marshmallow import validates, ValidationError

class UserSchema(Schema):
    age = fields.Int()

    @validates('age')
    def validate_age(self, value):
        if value < 0:
            raise ValidationError('Age must be positive.')
        if value > 150:
            raise ValidationError('Age seems unrealistic.')
```

### Handle Unknown Fields

```python
from marshmallow import Schema, EXCLUDE, INCLUDE, RAISE

class StrictSchema(Schema):
    class Meta:
        unknown = RAISE  # Raise error on unknown fields

class FlexibleSchema(Schema):
    class Meta:
        unknown = INCLUDE  # Include unknown fields

class FilteringSchema(Schema):
    class Meta:
        unknown = EXCLUDE  # Silently ignore unknown fields
```

## Troubleshooting

### YAML parsing error with swagger-marshmallow-codegen

If you see:
```
INFO:dictknife.loading._lazyimport:yaml package is not found
TypeError: JSONDecoder.__init__() got an unexpected keyword argument 'loader'
```

Use JSON format instead:
```bash
# Convert YAML to JSON first, or export as JSON from Swagger
swagger-marshmallow-codegen api_spec.json models.py
```

### ValidationError not raised

Make sure you're using `load()` not `dump()`:
- `load()` - deserializes AND validates
- `dump()` - serializes only, no validation

### Field name mismatches

Use `data_key` for different API field names:

```python
class UserSchema(Schema):
    first_name = fields.Str(data_key="firstName")
```

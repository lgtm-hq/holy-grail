## What is Starship?

Starship is a minimal, fast, and customizable prompt for any shell. It is
written in Rust and works across Bash, Zsh, Fish, and more. It replaces
theme-based prompt systems (like Oh My Zsh themes or Powerlevel10k) with a
single, cross-shell configuration.

## What is Ghostty?

Ghostty is a GPU-accelerated terminal emulator focused on speed, correctness,
and native platform integration. It supports ligatures, true color, and custom
themes out of the box.

## Install Nerd Fonts

Starship uses special glyphs for Git status, language icons, and other
indicators. You need a patched **Nerd Font** to render them properly.

<Tabs tabs={["macOS", "Linux"]}>
<Fragment slot="macOS">

```bash
brew install --cask font-meslo-lg-nerd-font
```

Other popular choices:

```bash
brew install --cask font-jetbrains-mono-nerd-font
brew install --cask font-fira-code-nerd-font
```

</Fragment>
<Fragment slot="Linux">

```bash
# Download and install manually
mkdir -p ~/.local/share/fonts
cd ~/.local/share/fonts
curl -fLO https://github.com/ryanoasis/nerd-fonts/releases/latest/download/Meslo.tar.xz
tar -xf Meslo.tar.xz
fc-cache -fv
```

</Fragment>
</Tabs>

## Install Ghostty

<Tabs tabs={["macOS", "Linux"]}>
<Fragment slot="macOS">

```bash
brew install --cask ghostty
```

</Fragment>
<Fragment slot="Linux">

Ghostty provides packages for major distributions. See the
[Ghostty installation docs](https://ghostty.org/docs/install) for your distro.

</Fragment>
</Tabs>

### Configure Ghostty

Create `~/.config/ghostty/config`:

```
font-family = MesloLGS Nerd Font
font-size = 14

theme = Argonaut
background-opacity = 0.95

window-padding-x = 8
window-padding-y = 8
```

> Browse available themes with `ghostty +list-themes` in terminal.

## Install Starship

<Tabs tabs={["macOS", "Linux"]}>
<Fragment slot="macOS">

```bash
brew install starship
```

</Fragment>
<Fragment slot="Linux">

```bash
curl -sS https://starship.rs/install.sh | sh
```

This installs to `/usr/local/bin/starship`.

</Fragment>
</Tabs>

### Initialize Starship

Add to your `~/.zshrc`:

```bash
command -v starship &>/dev/null && eval "$(starship init zsh)"
```

> Using a `command -v` guard ensures the shell does not error if Starship is not
> installed on a particular machine. This is important for shared dotfiles.

### Choose a Preset

Starship includes several presets to get started quickly:

```bash
# List available presets
starship preset --list

# Apply a preset (e.g., Tokyo Night)
starship preset tokyo-night -o ~/.config/starship.toml
```

### Customize Starship

Edit `~/.config/starship.toml` to tailor the prompt:

```toml
[directory]
truncation_length = 3
truncation_symbol = "…/"

[git_branch]
symbol = " "

[git_status]
conflicted = "⚡"
ahead = "⇡${count}"
behind = "⇣${count}"

[cmd_duration]
min_time = 500
format = "took [$duration](bold yellow) "

[time]
disabled = false
format = "[$time]($style) "
time_format = "%H:%M"
```

### Manage with Dotfiles

To manage Starship config with GNU Stow:

```bash
mkdir -p ~/my-dotfiles/shared/starship/.config
mv ~/.config/starship.toml ~/my-dotfiles/shared/starship/.config/starship.toml
stow -d shared -t ~ starship
```

## Companion CLI Tools

These modern CLI tools integrate well with a Starship + Ghostty setup.

### zoxide — Smarter `cd`

zoxide learns your most-used directories and lets you jump to them with
partial names.

<Tabs tabs={["macOS", "Linux"]}>
<Fragment slot="macOS">

```bash
brew install zoxide
```

</Fragment>
<Fragment slot="Linux">

```bash
curl -sS https://raw.githubusercontent.com/ajeetdsouza/zoxide/main/install.sh | bash
```

Installs to `~/.local/bin`. Ensure this is on your `PATH`.

</Fragment>
</Tabs>

Add to your `~/.zshrc`:

```bash
command -v zoxide &>/dev/null && eval "$(zoxide init zsh)"
```

Usage:

```bash
# Jump to a frequently-used directory
z projects

# Interactive selection
zi
```

### eza — Modern `ls`

eza is a modern replacement for `ls` with colors, icons, and Git integration.

<Tabs tabs={["macOS", "Linux"]}>
<Fragment slot="macOS">

```bash
brew install eza
```

</Fragment>
<Fragment slot="Linux">

```bash
sudo apt install eza
```

</Fragment>
</Tabs>

Add an alias to your `~/.zshrc`:

```bash
command -v eza &>/dev/null && alias ls='eza -la --icons'
```

## Troubleshooting

### Icons display as squares or question marks

You are missing a Nerd Font or your terminal is not configured to use it.
Verify:
1. A Nerd Font is installed (`fc-list | grep -i nerd` on Linux)
2. Your terminal's font is set to the Nerd Font (Ghostty: `font-family` in config)

### `command not found: starship` after install

On Linux, the installer places Starship in `/usr/local/bin`. Ensure this is on
your `PATH`:

```bash
export PATH="/usr/local/bin:$PATH"
```

### Starship prompt is slow

Starship scans the current directory for language files, Git status, etc. In
very large repos, this can be slow. Disable expensive modules:

```toml
# ~/.config/starship.toml
[git_status]
disabled = true
```

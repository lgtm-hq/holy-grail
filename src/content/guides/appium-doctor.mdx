## What is Appium Doctor?

Appium Doctor is a command-line tool that diagnoses and validates your Appium
installation. It checks all the necessary dependencies for both iOS and Android
testing are properly configured.

> Run Appium Doctor before troubleshooting test failures -- it quickly identifies
> common configuration issues.

## Installation

```bash
npm i --location=global @appium/doctor
```

Close your terminal session after installation.

## Verify Your Installation

Open a new terminal session:

```bash
appium-doctor --version
```

## Run Diagnostics

### Full Diagnostic Check

```bash
appium-doctor
```

### iOS-Specific Check

```bash
appium-doctor --ios
```

### Android-Specific Check

```bash
appium-doctor --android
```

## Understanding the Output

Appium Doctor uses symbols to indicate status:

| Symbol | Meaning |
|--------|---------|
| ✔ | Check passed |
| ✖ | Check failed (required fix) |
| ⚠ | Warning (optional fix) |

### Common Checks Performed

**iOS Checks:**
- <LinkBadge href="/guides/xcode/" /> is installed and has required simulators
- Xcode Command Line Tools configured
- <LinkBadge href="/guides/carthage/" /> installed (if using WebDriverAgent)
- <LinkBadge href="/guides/ios-deploy/" /> installed for real device testing
- <LinkBadge href="/guides/libimobiledevice/" /> installed for device communication

**Android Checks:**
- ANDROID_HOME environment variable set
- JAVA_HOME environment variable set
- Android SDK platform-tools in PATH
- Android SDK build-tools installed
- Emulator available

## Fixing Common Issues

### ANDROID_HOME Not Set

Add to your `~/.zshrc` or `~/.bashrc`:

```bash
export ANDROID_HOME=$HOME/Library/Android/sdk
export PATH=$PATH:$ANDROID_HOME/platform-tools
export PATH=$PATH:$ANDROID_HOME/emulator
```

### JAVA_HOME Not Set

If using SDKMAN:

```bash
export JAVA_HOME=$HOME/.sdkman/candidates/java/current
```

### Xcode Command Line Tools Not Configured

```bash
sudo xcode-select --switch /Applications/Xcode.app/Contents/Developer
```

## Troubleshooting

### "appium-doctor: command not found"

The npm global bin directory may not be in your PATH:

```bash
# Find npm global directory
npm config get prefix

# Add to PATH in ~/.zshrc
export PATH="$(npm config get prefix)/bin:$PATH"
```

### Checks Pass But Tests Still Fail

Appium Doctor checks environment setup, not all runtime issues. If checks pass but
tests fail:

1. Check Appium server logs for detailed errors
2. Verify the device/simulator is properly connected
3. Ensure the app under test is properly signed (iOS)
4. Run `appium-doctor` with verbose output:
   ```bash
   appium-doctor --verbose
   ```

### "Necessary" vs "Optional" Checks

- **Necessary (✖)**: Must be fixed for Appium to work
- **Optional (⚠)**: Recommended but not required

Focus on fixing necessary issues first before addressing optional warnings.

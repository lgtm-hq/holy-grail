## What is This Guide?

This is a curated list of recommended macOS applications for software developers
and QA engineers. The list covers productivity tools, utilities, IDEs, browsers,
communication apps, and more. All apps are categorized with notes on pricing and
alternatives.

> This guide focuses on app recommendations. For installation of development
> tools (Homebrew, Node.js, Python, etc.), see their dedicated guides.

## Password Managers

Choose one password manager and use it consistently across all your devices:

| App | Pricing | Notes |
|-----|---------|-------|
| [1Password](https://1password.com/) | Paid | Built-in authenticator, family/team sharing |
| [Bitwarden](https://bitwarden.com/) | Free / Paid | Open source, self-hostable |
| [Dashlane](https://www.dashlane.com/) | Paid | VPN included in premium |
| Apple Keychain | Free | Built into macOS, syncs via iCloud |

> Some password managers (like 1Password) have a built-in authenticator app,
> which can replace a separate 2FA app.

## Good to Know

### Installing Apps

Most apps can be installed via:

- **Mac App Store** -- Sandboxed, auto-updates
- **Homebrew Cask** -- `brew install --cask <app-name>`
- **Direct download** -- From the developer's website

Homebrew Cask is convenient for automating installations:

```bash
brew install --cask raycast rectangle iterm2 visual-studio-code
```

### Uninstalling Apps

Dragging an app to the Trash does not remove all its files. Use
[AppCleaner](https://freemacsoft.net/appcleaner/) to fully remove apps and
their associated preferences, caches, and support files.

For development tools, see the uninstalling sections in their dedicated guides.

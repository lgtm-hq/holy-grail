## What is Pipenv?

[Pipenv](https://pipenv.pypa.io/) is a packaging tool for Python that solves some
common problems associated with the typical workflow using `pip`, `virtualenv`, and
`requirements.txt`. It consolidates and simplifies the development process to a single
command line tool.

> - You no longer need to use `pip` and `virtualenv` separately. They work together.
> - Managing a `requirements.txt` file can be problematic, so Pipenv uses the
>   `Pipfile` instead, which is superior for basic use cases.
> - Hashes are used everywhere, always. Security. Automatically expose security
>   vulnerabilities.

## Installation

Open a new terminal session and run:

```bash
brew install pipenv
```

Close your terminal session after installation.

## Verify Your Installation

Open a new terminal session:

```bash
pipenv --version
```

## Install Packages

Open a new terminal session.

**Install a production dependency:**

```bash
pipenv install <package-name>
```

This adds the package to the `[packages]` section in your `Pipfile`:

```toml
[packages]
<package-name> = "*"
```

**Installation with version specifiers:**

```bash
pipenv install "package_name<1.2"
pipenv install "package_name<=1.2"
pipenv install "package_name>1.2"
pipenv install "package_name>=1.2"
pipenv install "package_name==1.*"
pipenv install "package_name==1.2.*"
pipenv install "package_name==1.2.3"
```

> It's always good to **lock package versions**. This means changing `= "*"` to
> `= "==1.2.3"`. Using `= "*"` means that it will always just install the latest
> available version of that package.

## Install Dev Packages

Assuming you have a package that is not yet a requirement for your project, that
dependency will be added/found under the `[dev-packages]` section in your `Pipfile`.

You can install that package with the same `pipenv install` command, but include the
`--dev` flag:

```bash
pipenv install <package-name> --dev
```

This adds the package to `[dev-packages]`:

```toml
[dev-packages]
<package-name> = "*"
```

**Install dev requirements from requirements.txt:**

```bash
pipenv install -r requirements.txt --dev
```

## Uninstall Packages

Open a new terminal session.

**Uninstall a specific package:**

```bash
pipenv uninstall <package_name>
```

**Uninstall all packages:**

```bash
pipenv uninstall --all
```

**Uninstall only dev packages:**

```bash
pipenv uninstall --all-dev
```

## Using the Virtual Environment

### Creating a Virtual Environment

Open a new terminal session.

**Optionally name your virtual environment:**

```bash
export PIPENV_CUSTOM_VENV_NAME=your_venv_name
```

**Create your virtual environment with dependencies:**

```bash
pipenv install
```

**Install using the lockfile (ignore Pipfile):**

```bash
pipenv install --ignore-pipfile
```

> The `--ignore-pipfile` flag tells Pipenv to install strictly from an existing
> `Pipfile.lock`, ignoring the `Pipfile` entirely. If no `Pipfile.lock` is present,
> a virtual environment will be created but no dependencies will be installed.
> Pipenv does **not** fall back to `requirements.txt`.

**Specify a Python version:**

If you did not specify a Python version in your `Pipfile` and want to use a specific
version:

```bash
pipenv --python <version>
```

> The version you specify must already be installed on your machine.

### Activating a Virtual Environment

Keep in mind that `pipenv` is now a replacement for the default `pip` command. Both
commands can and do still work with your virtual environment, but using `pip` will only
install to your virtual environment and will **not** update your `Pipfile` or
`Pipfile.lock`.

```bash
pipenv shell
```

### Deactivating a Virtual Environment

```bash
exit
```

### Run a Single Command

```bash
pipenv run python script.py
pipenv run pytest
```

## Pipfile Example

```toml
[[source]]
url = "https://pypi.org/simple"
verify_ssl = true
name = "pypi"

[packages]
requests = "*"
flask = "~=2.0"

[dev-packages]
pytest = "*"
black = "*"

[requires]
python_version = "3.11"
```

## Good to Know

### Managing Dependencies (requirements)

**Migrating from requirements.txt to Pipenv:**

```bash
pipenv install
```

> This command will detect if there's a `requirements.txt` file in your project and
> use it.

**Specifically install dependencies from requirements.txt:**

```bash
pipenv install -r requirements.txt
```

**Export installed dependencies from your virtual environment to a requirements.txt and
create the Pipfile and Pipfile.lock:**

```bash
pipenv run pip freeze > requirements.txt && pipenv install -r requirements.txt
```

**Generate requirements.txt from Pipfile:**

```bash
pipenv requirements > requirements.txt

# Include dev dependencies
pipenv requirements --dev > requirements-dev.txt

# Only dev dependencies (excludes production packages)
pipenv requirements --dev-only > requirements-dev-only.txt

# Include hashes for secure installs
pipenv requirements --hash > requirements.txt
```

### Update Pipfile

To update (or create if not already there) a `Pipfile` file with your installed
dependencies:

```bash
pipenv lock
```

> This will create a `Pipfile.lock` with the hashes of all the installed dependencies.

### Version Specifiers

| Specifier | Meaning |
|-----------|---------|
| `*` | Any version |
| `==1.0` | Exactly 1.0 |
| `>=1.0` | 1.0 or higher |
| `~=1.0` | Compatible with 1.0 (>=1.0, \<2.0) |
| `!=1.5` | Any version except 1.5 |

### Locate Your Virtual Environment

**Location of your virtual environment:**

```bash
pipenv --venv
```

**Location of your project home:**

```bash
pipenv --where
```

> All virtual environments can be found in: `/Users/{user}/.local/share/virtualenvs`

### Check for Security Vulnerabilities

```bash
pipenv check
```

### Show Dependency Graph

```bash
pipenv graph
```

### Remove Virtual Environment

```bash
pipenv --rm
```

## Environment Variables

Pipenv automatically loads variables from a `.env` file in your project root:

```bash
# .env
DATABASE_URL=postgres://localhost/mydb
SECRET_KEY=your-secret-key
```

## Troubleshooting

### "Pipfile.lock is out of date"

```bash
pipenv lock
pipenv install
```

### Clear Cache

```bash
pipenv --clear
```

### Specify Python Version

```bash
pipenv --python 3.11
```

### Use System Python

```bash
pipenv --python $(which python3)
```

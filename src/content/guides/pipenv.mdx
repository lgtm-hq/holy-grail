## What is Pipenv?

[Pipenv](https://pipenv.pypa.io/) is a packaging tool for Python that combines `pip`
and `virtualenv` into a single workflow. It replaces `requirements.txt` with the
`Pipfile` format and generates a lockfile for deterministic builds.

> For a comparison of Pipenv with other tools (uv, Poetry), see
> <LinkBadge href="/guides/virtual-environments/" />.

## Installation

```bash
brew install pipenv
```

Close your terminal session after installation.

## Verify Your Installation

Open a new terminal session:

```bash
pipenv --version
```

## Install Packages

**Install a production dependency:**

```bash
pipenv install <package-name>
```

**Install with a version specifier:**

```bash
pipenv install "package_name~=1.2"
pipenv install "package_name==1.2.3"
```

**Install a dev dependency:**

```bash
pipenv install <package-name> --dev
```

> For a full guide on version specifiers and updating dependencies, see
> <LinkBadge href="/guides/update-dependencies/" />.

## Uninstall Packages

```bash
# Uninstall a specific package
pipenv uninstall <package_name>

# Uninstall all packages
pipenv uninstall --all

# Uninstall only dev packages
pipenv uninstall --all-dev
```

## Pipfile Example

```toml
[[source]]
url = "https://pypi.org/simple"
verify_ssl = true
name = "pypi"

[packages]
requests = "*"
flask = "~=2.0"

[dev-packages]
pytest = "*"
black = "*"

[requires]
python_version = "3.11"
```

## Migrating from requirements.txt

**Auto-detect and import existing requirements.txt:**

```bash
pipenv install
```

> Pipenv will detect a `requirements.txt` in your project directory and import it
> automatically.

**Explicitly import from requirements.txt:**

```bash
pipenv install -r requirements.txt
```

**Generate requirements.txt from Pipfile:**

```bash
pipenv requirements > requirements.txt

# Include dev dependencies
pipenv requirements --dev > requirements-dev.txt

# Include hashes for secure installs
pipenv requirements --hash > requirements.txt
```

## Useful Commands

### Check for Security Vulnerabilities

```bash
pipenv check
```

### Show Dependency Graph

```bash
pipenv graph
```

### Environment Variables

Pipenv automatically loads variables from a `.env` file in your project root:

```bash
# .env
DATABASE_URL=postgres://localhost/mydb
SECRET_KEY=your-secret-key
```

### Run a Single Command

Without activating the shell:

```bash
pipenv run python script.py
pipenv run pytest
```

## What is Pydantic?

[Pydantic](https://docs.pydantic.dev/) is a data validation library for Python that uses type hints to validate data. It's the most widely used data validation library in Python, known for its speed (with a Rust core in v2) and ease of use.

> Pydantic is the default validation library for FastAPI and is excellent for validating API request/response schemas.

## Basic Usage

### Define a Model

```python
from pydantic import BaseModel
from typing import Optional

class User(BaseModel):
    id: int
    name: str
    email: str
    is_active: bool = True
    age: Optional[int] = None
```

### Validate Data

```python
# Valid data
user = User(id=1, name="John Doe", email="john@example.com")
print(user.model_dump())
# {'id': 1, 'name': 'John Doe', 'email': 'john@example.com', 'is_active': True, 'age': None}

# Invalid data raises ValidationError
from pydantic import ValidationError

try:
    user = User(id="not_an_int", name="John", email="john@example.com")
except ValidationError as e:
    print(e.errors())
```

## API Validation Examples

### Validate Request Data

```python
from pydantic import BaseModel, ValidationError

class CreateUserRequest(BaseModel):
    first_name: str
    last_name: str
    email: str

data = {
    "first_name": "Jane",
    "last_name": "Doe",
    "email": "jane@example.com"
}

try:
    validated = CreateUserRequest(**data)
    # Proceed with API request using validated.model_dump()
except ValidationError as e:
    print(f"Validation failed: {e}")
```

### Validate Response Data

```python
import requests

response = requests.get("https://api.example.com/users/1")

try:
    user = User(**response.json())
    print(f"Valid user: {user.name}")
except ValidationError as e:
    raise AssertionError(f"Response schema mismatch: {e}")
```

## Advanced Features

### Field Validation

```python
from pydantic import BaseModel, field_validator, Field

class User(BaseModel):
    name: str = Field(min_length=1, max_length=100)
    age: int = Field(ge=0, le=150)
    email: str

    @field_validator('email')
    @classmethod
    def validate_email(cls, v):
        if '@' not in v:
            raise ValueError('Invalid email format')
        return v.lower()
```

### Nested Models

```python
class Address(BaseModel):
    street: str
    city: str
    country: str

class User(BaseModel):
    name: str
    address: Address
    tags: list[str] = []
```

### Model Configuration

```python
from pydantic import BaseModel, ConfigDict

class StrictUser(BaseModel):
    model_config = ConfigDict(
        strict=True,           # No type coercion
        extra='forbid',        # Error on extra fields
        frozen=True,           # Immutable instances
    )

    name: str
    age: int
```

### JSON Schema Export

```python
class User(BaseModel):
    name: str
    email: str

# Export as JSON Schema
print(User.model_json_schema())
```

### Alias for API Field Names

```python
from pydantic import BaseModel, ConfigDict, Field

class User(BaseModel):
    model_config = ConfigDict(populate_by_name=True)

    first_name: str = Field(alias="firstName")
    last_name: str = Field(alias="lastName")

# Can parse with either name
user = User(firstName="John", lastName="Doe")
# Or
user = User(first_name="John", last_name="Doe")
```

## Pydantic v1 vs v2

If you're migrating from v1:

| v1 | v2 |
|----|-----|
| `class Config` | `model_config = ConfigDict()` |
| `.dict()` | `.model_dump()` |
| `.json()` | `.model_dump_json()` |
| `@validator` | `@field_validator` |
| `parse_obj()` | `model_validate()` |

## Troubleshooting

### "value is not a valid integer"

Pydantic v2 strict mode doesn't coerce types. Either:
- Ensure input types match the model
- Use `strict=False` in ConfigDict

### Optional fields still required

Use `Optional` with a default value:

```python
# This is still required (no default)
field: Optional[str]

# This is truly optional
field: Optional[str] = None
```

### Extra fields causing errors

By default, extra fields are ignored. To change:

```python
model_config = ConfigDict(extra='forbid')  # Raise error
model_config = ConfigDict(extra='allow')   # Include them
model_config = ConfigDict(extra='ignore')  # Silently drop (default)
```
